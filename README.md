## About

GATE Preparation Platform is a comprehensive web application designed to provide everything required for GATE Computer Science preparation in one place.

🔗 **Website:** https://gate-eosin-beta.vercel.app/

The platform combines structured learning, chapter-wise practice, official previous year papers, a GATE CBT exam simulator, performance analytics, progress tracking, bookmarks, and a personalized learning experience into a single application.

Whether you're preparing for **GATE 2026, 2027, 2028, or any future examination**, the platform allows you to select your target exam year and manage your preparation from one place.

---


## Features

- Interactive Learning Center
- Topic-wise Practice Questions
- Previous Year Question Papers (PYQs)
- GATE CBT Exam Simulator
- Performance Analytics
- Personalized Dashboard
- Bookmark & Revision System
- Syllabus Progress Tracking
- Dark & Light Theme
- Offline Progress Storage using Local Storage
- Fully Responsive Design
